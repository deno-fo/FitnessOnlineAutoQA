# Запуск iOS-автотестов на реальном устройстве

Инструкция предназначена для тестировщиков, которые раньше не работали с Java, Maven, Appium и Xcode.
iOS-автотесты запускаются только на Mac и только на реальном iPhone.

## Важно перед началом настройки

Appium не управляет iPhone напрямую.
Для управления устройством Appium использует служебное приложение `WebDriverAgent`, сокращённо `WDA`.

При первом запуске WDA:
1. собирается в Xcode;
2. подписывается сертификатами Apple Developer Team;
3. устанавливается на подключённый iPhone;
4. запускается на устройстве;
5. передаёт команды от Appium приложению FitnessOnline.

Поэтому перед запуском тестов необходимо, чтобы:
- тестировщик имел доступ к Apple Developer Team `FITNESS ONLINE MChJ`;
- нужный Apple Account был добавлен в Xcode;
- для аккаунта был доступен раздел `Certificates, Identifiers, & Profiles`;
- iPhone был подключён к Mac и переведён в режим разработчика;
- WebDriverAgent был успешно подписан и запущен на iPhone;
- iPhone был зарегистрирован в Apple Developer Team;
- регистрация устройства была обработана Apple.

Полный порядок настройки описан ниже. Проходите разделы по порядку и не пропускайте первичную настройку WebDriverAgent.

Новое устройство может получить состояние `Processing`.
Пока устройство находится в этом состоянии, WebDriverAgent может не собираться или не устанавливаться, а iOS-тесты не запустятся.

> [!WARNING]
> **Обработка нового iPhone может занять до 72 часов, поэтому первичную настройку нового iPhone необходимо выполнять заранее.**

## 1. Что нужно установить
На Mac должны быть установлены:
1. Git: https://git-scm.com/downloads
2. IntelliJ IDEA: https://www.jetbrains.com/idea/download/
3. Java JDK 17: https://adoptium.net/
4. Node.js 24: https://nodejs.org/
5. Xcode из App Store
6. Appium 3.5.2
7. iOS-драйвер Appium XCUITest 11.17.4
Appium и драйвер XCUITest будут установлены позже в ходе прохождения инструкции.

Также понадобятся:
- реальный iPhone;
- USB-кабель;
- установленное приложение FitnessOnline;
- доступ к приватному репозиторию GitHub;
- доступ к Apple Developer Team `FITNESS ONLINE MChJ`;

Отдельно будут установлены Maven и npm:
- Maven проект скачает автоматически;
- npm устанавливается вместе с Node.js;
- команды `xcrun` и `xctrace` устанавливаются вместе с Xcode.

## 2. Получение доступа к GitHub
Репозиторий приватный. Без приглашения открыть или скачать его нельзя.

### Что должен сделать владелец репозитория
1. Узнать имя пользователя тестировщика на GitHub.
2. Открыть репозиторий.
3. Перейти в `Settings` → `Collaborators`.
4. Нажать `Add people`.
5. Найти тестировщика по имени пользователя.
6. Отправить приглашение.

### Что должен сделать тестировщик
1. Открыть письмо или уведомление от GitHub.
2. Принять приглашение.
3. После этого репозиторий станет доступен его аккаунту.

## 3. Получение доступа к Apple Developer Team
Для подписи WebDriverAgent нужен Apple Account, добавленный в команду `FITNESS ONLINE MChJ`.

Это не обязательно должен быть Apple Account, который используется для входа на Mac или на самом iPhone.
Apple Account на Mac, Apple Account на iPhone и рабочий Apple Account разработчика могут быть разными.

Нужно использовать именно тот аккаунт, на который было отправлено приглашение в Apple Developer Team.

## 4. Добавление Apple Account в Xcode и проверка доступа
1. Откройте Xcode.
2. Примите лицензионное соглашение, если Xcode показывает такой запрос.
3. Дождитесь установки дополнительных компонентов.
4. В верхнем меню выберите `Xcode` → `Settings`.
5. Откройте раздел `Apple Accounts`.
6. Нажмите кнопку `+`.
7. Выберите добавление Apple Account.
8. Войдите в рабочий аккаунт, добавленный в команду.
9. Выберите команду `FITNESS ONLINE MChJ`.

В информации о команде должно отображаться:
```text
Role
Developer
```

Также возле строки:
```text
Certificates, Identifiers, & Profiles
```
должна стоять зелёная галка.
Это означает, что аккаунту разрешён доступ к сертификатам, идентификаторам и профилям команды.

Если указана роль `Developer` и стоит зелёная галка, необходимый доступ получен.

Если:
- команда `FITNESS ONLINE MChJ` отсутствует;
- указана другая команда;
- вместо роли `Developer` указана другая роль;
- возле `Certificates, Identifiers, & Profiles` нет зелёной галки;
- аккаунт не отображается в Xcode;

необходимо обратиться к администратору или владельцу Apple Developer Team.
Самостоятельно менять `TEAM_ID` в проекте в таком случае не нужно.

## 5. Установка Appium
Откройте системное приложение `Терминал`.

Чтобы открыть Терминал:
1. Нажмите `Command + Space`.
2. Введите:
```text
Terminal
```
3. Откройте найденное приложение.

Установите Appium:
```bash
npm install --global appium@3.5.2
```

Установите iOS-драйвер XCUITest:
```bash
appium driver install xcuitest@11.17.4
```

Проверьте установку:
```bash
appium driver doctor xcuitest
```

Если в результате написано:
```text
0 required fixes needed
```
обязательные компоненты установлены.

После установки полностью перезапустите IntelliJ IDEA.

## 6. Загрузка проекта
1. Откройте IntelliJ IDEA.
2. На стартовом экране нажмите `Get from VCS` или `Clone Repository`.
3. Вставьте адрес:
```text
https://github.com/deno-fo/FitnessOnlineAutoQA.git
```
4. Нажмите `Clone`.
5. Если IDEA попросит войти в GitHub, войдите под аккаунтом, которому выдали доступ.
6. Разрешите IntelliJ IDEA доступ к GitHub.
7. Откройте загруженный проект.
8. Дождитесь завершения загрузки Maven-зависимостей.

При первой загрузке это может занять несколько минут.

## 7. Где вводить команды проекта
Команды запуска тестов нужно вводить в терминале внутри IntelliJ IDEA.

Чтобы его открыть:
1. В верхнем меню IDEA нажмите `View`.
2. Выберите `Tool Windows`.
3. Нажмите `Terminal`.

Вкладка `Terminal` также может находиться в нижней части окна IDEA.
Перед вводом команды посмотрите на строку слева от курсора. В ней должно присутствовать название проекта:
```text
FitnessOnlineAutoQA
```

Пример:
```text
admin@MacBook FitnessOnlineAutoQA %
```

Если названия проекта нет, команда введена не в папке проекта.
Закройте терминал и откройте его заново через IntelliJ IDEA.

Команды первичной настройки Xcode и WebDriverAgent можно выполнять в системном Терминале.
Команды запуска тестов необходимо выполнять в терминале IntelliJ IDEA, открытом в папке проекта.

## 8. Настройки Apple Developer Team в проекте
Настройки команды находятся в файле:
```text
src/test/java/utils/IosConfig.java
```

В нём указаны:
```text
TEAM_ID
WDA_BUNDLE_ID
```

Обычному тестировщику самостоятельно искать, придумывать или изменять эти значения не нужно.
Значения меняются только в следующих случаях:
- проект переносится в другую Apple Developer Team;
- владелец проекта сообщил новые значения;
- изменился Bundle ID WebDriverAgent.

Если Xcode не показывает команду `FITNESS ONLINE MChJ`, менять `TEAM_ID` в коде не нужно.
Необходимо получить доступ к правильной Apple Developer Team.

## 9. Подключение и проверка подключения iPhone
1. Подключите iPhone с помощью USB-кабеля.
2. Разблокируйте iPhone.
3. Если появился запрос доверия к компьютеру, нажмите `Доверять`.
4. Введите код-пароль iPhone.
5. Откройте на iPhone `Настройки`.
6. Перейдите в `Конфиденциальность и безопасность`.
7. Включите `Режим разработчика`.
8. Перезапустите iPhone, если система попросит это сделать.
9. После перезапуска подтвердите включение режима разработчика.
10. Снова подключите и разблокируйте iPhone.

Команду проверки необходимо вводить в системном приложении `Терминал` на Mac.

В окне Терминала выполните:
```bash
xcrun xctrace list devices
```
Нажмите `Enter`.

Найдите раздел:
```text
== Devices ==
```
В нём должен отображаться подключённый iPhone.

Пример:
```text
Admin's iPhone (26.5) (00008140-000202E136D2801C)
```

В этой строке:
- `Admin's iPhone` является именем устройства;
- последняя длинная строка в скобках является UDID устройства.

Сохраните имя и UDID устройства.
Они могут понадобиться для проверки регистрации iPhone в Apple Developer Team.

Имя и UDID вручную в коде указывать не нужно.
Фреймворк автоматически находит единственный подключённый iPhone и передаёт его данные Appium.
На текущий момент одновременно к Mac должен быть подключён только один физический iPhone.

Если подключено несколько iPhone, тест завершится с ошибкой и попросит оставить одно устройство.

## 10. Первичная настройка WebDriverAgent
WebDriverAgent используется Appium для управления iPhone.
Настройка выполняется один раз на новом Mac или после полной переустановки iOS-драйвера Appium.
Подключите iPhone к Mac и разблокируйте его.
Откройте системный Терминал и выполните:
```bash
appium driver run xcuitest open-wda
```

После этого проект WebDriverAgent откроется в Xcode.

В Xcode:
1. В левой панели выберите проект `WebDriverAgent`.
2. В разделе `Targets` выберите `WebDriverAgentRunner`.
3. Откройте вкладку `Signing & Capabilities`.
4. Включите `Automatically manage signing`.
5. В поле `Team` выберите:
```text
FITNESS ONLINE MChJ
```
6. Убедитесь, что Xcode не показывает красную ошибку подписи.

Если Xcode просит указать Bundle Identifier, используйте значение `WDA_BUNDLE_ID` из файла:
```text
src/test/java/utils/IosConfig.java
```
Самостоятельно придумывать новый идентификатор не нужно.

Затем:
1. Откройте `Product` → `Scheme`.
2. Выберите `WebDriverAgentRunner`.
3. Откройте `Product` → `Destination`.
4. Выберите подключённый iPhone.
5. Нажмите `Product` → `Test`.

Xcode соберёт WebDriverAgent и попытается установить его на iPhone.
Во время этого запуска Xcode может автоматически зарегистрировать устройство в Apple Developer Team.

Если WebDriverAgent успешно установился и запустился, первичная настройка завершена.
После этого перейдите к следующему разделу и проверьте, зарегистрирован ли iPhone в Apple Developer Team.

Если Xcode показывает ошибку, связанную с регистрацией или подписью устройства, всё равно перейдите к следующему разделу и проверьте состояние iPhone.

## 11. Регистрация iPhone в Apple Developer Team
При использовании автоматической подписи Xcode обычно регистрирует подключённый iPhone во время первичного запуска WebDriverAgent.

После попытки запуска WebDriverAgent необходимо проверить, появилось ли устройство в Apple Developer Team.

### Проверка регистрации устройства
Проверить состояние можно на сайте Apple Developer:
Прямая ссылка - https://developer.apple.com/account/resources/devices/list
На случай изменений на сайте, пошагово:
1. Откройте браузер.
2. Перейдите на сайт Apple Developer.
3. Нажмите `Account`.
4. Войдите в рабочий Apple Account.
5. Выберите команду `FITNESS ONLINE MChJ`.
6. Откройте `Certificates, Identifiers & Profiles`.
7. Откройте раздел `Devices`.
8. Найдите iPhone по имени или UDID.

Имя и UDID были получены ранее командой:
```bash
xcrun xctrace list devices
```

Возможны следующие состояния:
- устройство активно и готово к работе, поле `Status` в таком случае пустое;
- устройство находится в состоянии `Processing`;
- устройство отсутствует в списке.

Если устройство активно, дополнительное ожидание не требуется.
Можно переходить к запуску тестов.

Если устройство находится в состоянии `Processing`, необходимо дождаться завершения обработки.
Она может занять до 72 часов.

Пока состояние `Processing` не исчезло, WebDriverAgent может не устанавливаться.
Повторно добавлять устройство или менять настройки проекта в этот период не нужно.

### Если устройство отсутствует в списке
Сначала повторите первичную настройку WebDriverAgent:
1. Убедитесь, что включено `Automatically manage signing`.
2. Убедитесь, что выбрана команда `FITNESS ONLINE MChJ`.
3. Убедитесь, что выбран подключённый iPhone.
4. Повторно нажмите `Product` → `Test`.

Если устройство всё равно не появилось, ручное добавление через Apple Developer Portal должен выполнить администратор или владелец команды.

Передайте администратору или владельцу:
- имя iPhone;
- UDID iPhone.

Администратор должен:
1. Открыть Apple Developer Account.
2. Выбрать команду `FITNESS ONLINE MChJ`.
3. Перейти в `Certificates, Identifiers & Profiles`.
4. Открыть раздел `Devices`.
5. Нажать кнопку `+`.
6. Выбрать `Register a Single Device`.
7. Выбрать платформу `iOS`.
8. Ввести имя устройства.
9. Вставить UDID.
10. Нажать `Continue`.
11. Проверить данные.
12. Нажать `Register`.
Прямая ссылка - https://developer.apple.com/account/resources/devices/list

После регистрации необходимо дождаться, пока устройство станет активным.
Срок ожидания тот же, что и при автоматическом добавлении - до 72 часов.

После исчезновения состояния `Processing` снова выполните первичную настройку WebDriverAgent из предыдущего раздела.
WebDriverAgent должен успешно установиться и запуститься на iPhone.

## 12. Обновление проекта
Перед запуском тестов получите последнюю версию проекта:
1. В верхнем меню IDEA откройте `Git`.
2. Нажмите `Pull`.
3. Дождитесь завершения обновления.

Если IDEA сообщает, что проект уже обновлён, ничего делать не нужно.

## 13. Подготовка iPhone перед тестом
Перед каждым запуском необходимо:

1. Подключить iPhone к Mac.
2. Разблокировать экран.
3. Убедиться, что включён режим разработчика.
4. Убедиться, что iPhone доверяет Mac.
5. Установить приложение FitnessOnline.
6. Переключить приложение FitnessOnline на английский язык.

Проверьте подключение в системном Терминале или в терминале IntelliJ IDEA:
```bash
xcrun xctrace list devices
```
iPhone должен отображаться в разделе подключённых устройств.

Одновременно к Mac должен быть подключён только один физический iPhone.

## 14. Запуск Appium
В терминале IntelliJ IDEA выполните:
```bash
appium
```

После запуска не закрывайте эту вкладку.
Appium должен работать всё время, пока выполняются тесты.

Для запуска тестов откройте вторую вкладку терминала кнопкой `+`.

## 15. Запуск всех iOS-тестов
Во второй вкладке терминала IntelliJ IDEA выполните:
```bash
./mvnw test -Pios
```
После этого все iOS-тесты запустятся на подключённом iPhone.

Во время выполнения:
- не отключайте кабель;
- не блокируйте iPhone;
- не закрывайте Appium;
- не нажимайте ничего в приложении вручную.

## 16. Запуск одного теста через IntelliJ IDEA
В левой части IDEA откройте:
```text
src → test → java → tests → ios
```

Названия iOS-тестов начинаются со слова `Ios`, например:
```text
IosGuestAccountCreationTest
```

Далее:
1. Откройте нужный файл двойным щелчком.
2. Нажмите зелёный треугольник рядом с названием класса.
3. Выберите `Run`.

Можно также нажать зелёный треугольник рядом с отдельным тестовым методом.

Файл `BaseIosTest` запускать не нужно. Это базовый класс с настройками драйвера.

## 17. Запуск одного теста командой
Например, для запуска `IosGuestAccountCreationTest`:
```bash
./mvnw test -Pios -Dtest=IosGuestAccountCreationTest
```

Команда вводится во второй вкладке терминала IntelliJ IDEA.

## 18. Состояние системных разрешений
iOS не позволяет Appium полностью сбрасывать системные разрешения приложения между тестами.

Это относится, например, к:
- Apple Health;
- уведомлениям;
- другим системным запросам доступа.

После первого разрешения или отказа системное окно может больше не появляться.
Поэтому некоторые тесты могут проходить по-разному в зависимости от текущего состояния приложения.

Для проверки сценария первого системного запроса может потребоваться:
1. удалить FitnessOnline с iPhone;
2. установить приложение заново;
3. снова запустить тест.

## 19. Результат запуска
Результат появится в том же терминале, в котором была запущена команда.

Успешный запуск выглядит примерно так:
```text
Failures: 0, Errors: 0
BUILD SUCCESS
```

Если `Failures` или `Errors` больше нуля, один или несколько тестов завершились с ошибкой.
Первый запуск может выполняться дольше обычного, потому что Appium собирает, подписывает и устанавливает WebDriverAgent.

## 20. Частые проблемы

### Команда `./mvnw` не найдена
Команда введена не в папке проекта.

Откройте терминал через IntelliJ IDEA и убедитесь, что в строке присутствует:
```text
FitnessOnlineAutoQA
```

### Команда `appium` не найдена
Appium не установлен или IntelliJ IDEA не была перезапущена после установки.

Выполните:
```bash
npm install --global appium@3.5.2
```
После этого полностью перезапустите IntelliJ IDEA.

### Команда `npm` не найдена
Node.js не установлен.
Установите Node.js 24 и перезапустите Терминал.

### Команда `xcrun` не найдена
Xcode не установлен или первоначальная настройка Xcode не завершена.
Откройте Xcode, примите лицензионное соглашение и дождитесь установки дополнительных компонентов.

### Команда `xcrun xctrace list devices` не показывает iPhone
Проверьте:
- подключён ли iPhone к Mac;
- разблокирован ли экран;
- подтверждено ли доверие к компьютеру;
- включён ли режим разработчика;
- отображается ли iPhone в Xcode;
- исправен ли кабель.

### В Xcode нет команды `FITNESS ONLINE MChJ`
Проверьте:
- добавлен ли правильный Apple Account;
- принято ли приглашение в Apple Developer Team;
- отправлено ли приглашение на правильную электронную почту.

Если команда отсутствует, обратитесь к администратору или владельцу Apple Developer Team.

### Возле `Certificates, Identifiers, & Profiles` нет зелёной галки
Для аккаунта не выдан нужный доступ.
Обратитесь к администратору или владельцу Apple Developer Team.
Менять `TEAM_ID` в коде не нужно.

### Устройство находится в состоянии `Processing`
Необходимо дождаться завершения автоматической обработки Apple.
Обработка может занять до 72 часов.
Пока устройство находится в состоянии `Processing`, WebDriverAgent может не устанавливаться.

### Устройство отсутствует в списке Apple Developer
Сначала повторите первичную настройку WebDriverAgent с включённым `Automatically manage signing`.
Xcode может зарегистрировать устройство автоматически.
Если автоматическая регистрация не произошла, передайте имя и UDID устройства администратору или владельцу команды для ручной регистрации.

### Ошибка подписи WebDriverAgent
Откройте проект WebDriverAgent:
```bash
appium driver run xcuitest open-wda
```

Проверьте:
- выбран ли `WebDriverAgentRunner`;
- включено ли `Automatically manage signing`;
- выбрана ли команда `FITNESS ONLINE MChJ`;
- возле `Certificates, Identifiers, & Profiles` есть зелёная галка;
- iPhone зарегистрирован в Apple Developer Team;
- состояние устройства не равно `Processing`;
- Xcode не показывает красную ошибку подписи.

Если ошибка остаётся, передайте владельцу проекта точный текст красной ошибки Xcode.

### Подключено несколько iPhone
Отключите все iPhone, кроме того, на котором должны запускаться тесты.

### Appium уже запущен
Не запускайте второй сервер.
Используйте уже открытую вкладку Appium.

### Первый запуск выполняется долго
При первом запуске Appium собирает и устанавливает WebDriverAgent.
Последующие запуски обычно выполняются быстрее.
