# FitnessOnlineAutoQA
Appium-автотесты мобильного приложения FitnessOnline для реальных Android- и iOS-устройств.

## Что покрыто на текущий момент
- создание гостевого аккаунта (с разными вариациями разрешений Health Connect);
- регистрация нового пользователя и авторизация существующего (с разными вариациями разрешений Health Connect);
- выбор готовой программы тренировок;
- создание и прохождение собственной тренировки;
- редактирование и удаление тренировочного дня.

> [!NOTE]
> Отдельный iOS-тест регистрации с разными вариантами разрешений пока не добавлен из-за особенностей сброса системных разрешений Apple Health. 
> Текущие iOS-тесты рассчитаны на предоставление всех запрашиваемых разрешений Apple Health.

## Архитектура и технические особенности
- **Кроссплатформенная автоматизация:** Android и iOS на реальных устройствах.
- **Технологический стек:** Java 17, JUnit 5, Maven и Appium 3.
- **Драйверы автоматизации:** UiAutomator2 для Android и XCUITest для iOS.
- **Разделение платформенной логики:** отдельные Page Object, компоненты и Flow-классы для Android и iOS.
- **Переиспользуемые сценарии:** регистрация, авторизация, onboarding, создание тренировок, выполнение упражнений и удаление тестовых данных вынесены в отдельные flows.
- **Автоматическое определение устройства:** имя и UDID подключённого Android-телефона или iPhone не требуется указывать вручную.
- **Отдельные Maven-профили** для запуска тестов каждой платформы:
    - `-Pandroid`
    - `-Pios`
- **Управление состоянием приложения:** тесты учитывают onboarding, системные разрешения, обучающие экраны, подсказки и различия между первым и повторным запуском.
- **Автоматическая очистка данных:** тестовые аккаунты удаляются после сценариев, а на Android перед каждым тестом очищаются данные приложения.
- **Удобное расширение:** новые тесты можно добавлять с использованием уже готовых шагов и платформенных настроек.
